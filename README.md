# 87版《红楼梦》交互式人物关系图谱

基于 87 版电视剧《红楼梦》经典角色形象打造的高保真、物理交互式全景人物关系知识图谱。

---

## 🌟 核心特色与功能

### 1. 节点设计：统一定制 87 版电视剧演员剧照
- **87版纯粹高清形象**：收录包含欧阳奋强（饰贾宝玉）、陈晓旭（饰林黛玉）、张莉（饰薛宝钗）、邓婕（饰王熙凤）在内的 **123 位原剧角色高清剧照头像**。
- **纯净面部呈现（头像绝无文字遮挡）**：彻底剔除在头像上覆盖姓氏的干扰，人物姓名与演员信息统一排布于头像正下方，字迹带有古典描边投影，清晰利落。
- **古典边框与印玺**：依照各大家族（荣国府、宁国府、史家、王家、薛家、林家、大观园丫鬟侍从、方外故旧）定制典雅国风徽标色系。
- **智能兜底**：当用户自行新增角色且暂未上传剧照时，系统自动生成雅致的朱砂/琥珀国风印玺头像。

### 2. 交互体验：物理弹簧动态拉伸、选中放大与自由固定
- **动态拉伸线条**：按住任意节点拖拽时，相连的关系线条如同**高弹性橡皮筋/弹簧般随鼠标动态拉伸伸展**，曲率、张力与中点关系标签实时动态计算，极具物理真实感与操作质感。
- **拉拽后保持落点（不自动复位）**：拖拽任意人物至新位置后，**节点将稳定驻留于落点位置，不会自动回弹复位**；连线保持拉伸，支持用户自由排版。双击节点可随时解除固定，或点击工具栏「🔓 释放全部固定」。
- **选中平滑放大**：鼠标**点击选中或悬停**任意人物时，头像与金色边框**平滑放大至 1.68 倍**，附带华丽光晕并自动提升至图层最顶层，细节一览无余；点击空白处即可平滑复原。
- **无级缩放与平移漫游**：支持鼠标滚轮、手势缩放、全图自适应居中（Fit to View）。
- **关系聚焦与悬浮高亮**：鼠标悬停在人物上时，自动半透明虚化无关节点，高亮一度关联邻居与连接纽带；点击人物后锁定高亮并展开生平手卷。

### 3. 层次感与防拥挤布局模式
- **🪐 核心圈层布局（默认）**：依照红楼梦宗法尊卑将 123 位角色划分为 4 大同心圆圈层：
  - **第 1 层（核心中枢）**：贾母、宝黛钗凤、贾政、王夫人、贾琏、贾珍等 12 位核心；
  - **第 2 层（正副册群芳与近支）**：元迎探惜、史湘云、李纨、妙玉、秦可卿、薛蟠、薛宝琴等；
  - **第 3 层（贴身大丫鬟与知己）**：晴雯、袭人、紫鹃、平儿、鸳鸯、龄官、北静王、柳湘莲等；
  - **第 4 层（外围故旧方外）**：甄士隐、贾雨村、刘姥姥、跛足道人、冷子兴等。
- **🏛️ 家族分区聚类**：荣国府、宁国府、史家、王家、薛家、林家、侍从、方外八大区域聚类。
- **🕸️ 自由弹性漫游**：无向心约束，纯弹簧斥力排布。
- **开阔呼吸间距**：排斥力提升至 `-1600`，弹性线长提升至 `220px`，碰撞安全缓冲达 `40px`，彻底告别密集成团。
- **智能精简连线文字**：默认隐藏次要交错文本，悬停或点击人物时瞬间高亮所有相连文字，保持画面清爽透彻。

### 3. 数据结构：高度可扩展与图形化管理
- **标准开放 Schema**：数据解耦独立保存在 `data/honglou_data.json` 与 `data/honglou_data.js` 中，遵循清晰规范的 JSON 数据格式（详见 [SCHEMA.md](SCHEMA.md)）。
- **页面内可视化扩充**：界面右上角提供 **「➕ 扩充数据」** 弹窗，支持在浏览器中直接新增角色、建立新关系链，并能一键**导出更新后的 JSON 数据**或导入自定义数据文件。

### 4. 丰富的高级功能
- **网站专属国风徽标与 Favicon（通灵朱玉 · 仙寿恒昌）**：
  - **文化意象**：汲取《红楼梦》“大荒山无稽崖青埂峰顽石”与贾宝玉所衔“通灵宝玉”之意象，将如意玉璧、朱砂温润玉髓、金镶玉回纹、同心丝绦与古典金石篆书“红”字融为一体。
  - **全端适配**：包含矢量自适应 SVG 图标（`brand-logo.svg`、`favicon.svg`）、多分辨率 Windows/Web `favicon.ico` 以及苹果移动端快捷图标（`apple-touch-icon.png`）。
  - **灵动交互**：导航栏品牌徽标支持悬停微光绽放与点击一键平滑漫游归位（Fit to View）。
- **5套预设透视**：
  - **经典核心**：精选 35 位核心主干角色，画面清爽、关系透彻，最适合教学与演示。
  - **全景宗族**：123 位角色、187 条关系全景铺开。
  - **金陵十二钗**：宝玉与金陵十二钗正册群芳专属视角。
  - **四大家族**：贾、史、王、薛四大家族宗族纽带。
  - **大观园情缘**：聚焦木石前盟、金玉良缘与大观园儿女痴情。
- **关系寻径（六度人脉算法）**：选择任意两位人物（如刘姥姥与贾宝玉），算法自动基于广度优先搜索（BFS）计算两人之间的**最短关系链路**，并在画布上高亮动态脉冲呈现。
- **人物生平手卷（Drawer）**：点击人物展开典雅手卷，呈现大观园居所、87版演员、原著判词、详尽生平性格评述与所有直接关联列表，点击关联卡片即可平滑飞往目标人物。
- **双模古典主题**：墨玉深色（默认）与素绢宣纸浅色主题一键切换。
- **高清图谱导出**：一键导出 2x 超高清 PNG 大图。

## 🚀 快速启动指南

### 方式一：直接双击打开（完全离线，推荐）
本项目的依赖（D3.js）与 123 张 87 版头像剧照已**全量离线本地化**：
- 直接在文件管理器中**双击打开 `index.html`**，即可在任意现代浏览器（Chrome、Edge、Safari、Firefox）中流畅运行，无任何跨域限制！

### 方式二：通过本地服务器运行
在项目目录下启动内置静态服务器：

```bash
# 使用 Python 启动本地服务
python -m http.server 8080
```

打开浏览器访问：`http://localhost:8080`

## 🎨 界面操作快捷键与手势

| 操作 | 行为效果 |
| :--- | :--- |
| **拖拽节点** | 自由拖拽人物，相连纽带实时弹性拉伸，松开后在弹簧拉力下平滑复位 |
| **双击节点** | 固定该节点当前位置（显示金钉）/ 再次双击解锁 |

| **关系寻径** | 点击顶部「🧭 关系寻径」，探寻任意两人的最短连接链路 |
| **导出图片** | 点击顶部「📷 导出图片」，将当前视角渲染保存为 2x 超高清 PNG |
